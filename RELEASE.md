# GitHub release 1.0.1 — in preparation

Candidate build151 excludes Pome, HomeKit camera helpers and Pome G2 resources. It leaves the separately installed Store edition unchanged.

Changes since1.0.0 include platform/sidebar navigation refinements; phone pairing through a QR/code page without Universal Clipboard; current Pingsquatch, Calendry and Remindery naming; current shared services and G2 web assets; attachment and reply-target improvements; and the GitHub updater correction so direct downloads use Sparkle rather than App Store updates.

Companion applications ship separately. This Connector release does not publish their pending builds or establish physical-device acceptance for them.

Publication is pending final artifact validation, Apple notarization and release-readiness evidence. The current public download remains1.0.0. No App Store submission is part of this release.

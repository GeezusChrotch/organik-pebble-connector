# Organik Apps Connector

The Mac connection for supported Organik apps on Pebble, Even G2 and Apple Watch.

**Current public GitHub download: 1.0.0. Version 1.0.1 is being prepared and is not yet public.**

[Download the current release](https://github.com/GeezusChrotch/organik-pebble-connector/releases/latest) · [Connector website](https://organikapps.com/connector/) · [Setup guide](PUBLIC-README.md) · [Privacy](PRIVACY.md)

The GitHub edition excludes Pome. The separate App Store edition retains Pome and Apple Home support; Store availability is announced separately. Companion apps install separately and availability varies by platform and app.

Requires macOS14 or later on Intel or Apple silicon. Connected features require an awake Mac running Connector and Tailscale on the Mac and phone, signed in to the same private network.

The upcoming release refreshes platform navigation, phone pairing, app names and services, and restores GitHub-specific update checks. See [release preparation](RELEASE.md) for the exact state. Pingsquatch was Beepster; Calendry was DayFrame/Eventz; Remindery was Reminderz. Existing technical identifiers are retained for compatibility.

The source in this repository includes historical release inputs. A documentation update does not certify that every source directory matches an unreleased candidate. Published binary identity is recorded by its version, build and release checksums.
